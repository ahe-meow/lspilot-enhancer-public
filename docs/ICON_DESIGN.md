# LSPilot Enhancer 图标设计

## 设计概念

新图标直接继承宿主 LSPilot 的品牌语言，并用一个独立角标标明增强模块身份：

- **宿主识别 / `LSP` 字标**：保留宿主图标中等粗、圆角、模块化的 `LSP` 几何字标，避免项目图标与宿主割裂；
- **增强能力 / 绿色 `+` 徽标**：右下绿色圆形徽标使用项目现有的成功状态色，表达功能扩展与 Hook 已加载；
- **工具属性 / 短下划线**：延续宿主字标下方的圆头短线，使图标仍具有终端、接口和系统工具的视觉语义；
- **自适应安全区**：字标相对宿主原图缩小约 10%，角标与主体保持重叠，兼顾圆形、圆角矩形和其他 Launcher 蒙版。

## 色彩

| 用途 | 色值 | 来源/含义 |
| --- | --- | --- |
| 渐变起点 | `#1037F4` | 宿主图标左上电光蓝 |
| 渐变中点 | `#087CF2` | 宿主图标主蓝 |
| 渐变终点 | `#05C8E7` | 宿主图标右下青蓝 |
| 字标浅蓝 | `#C3E0FF` | 宿主 `LSP` 高亮色 |
| 状态绿 | `#34C759` | 项目 Hook 成功与增强状态色 |
| 徽标前景 | `#FFFFFF` | 保证小尺寸下的 `+` 对比度 |

## Android 资源

- `res/drawable/ic_launcher_background.xml`：宿主风格的电光蓝到青蓝渐变背景；
- `res/drawable/ic_launcher_foreground.xml`：缩进安全区的 `LSP` 矢量字标与增强徽标；
- `res/mipmap-anydpi-v26/ic_launcher*.xml`：Android 8+ 自适应图标；
- `res/mipmap-anydpi/ic_launcher*.xml`：兼容资源；
- `docs/icon-source.svg`：1024 × 1024 可编辑发布源稿。

图标保留宿主的第一眼识别度，但绿色徽标让用户在 LSPosed、Launcher 和系统应用列表中能立即区分宿主与增强模块。
